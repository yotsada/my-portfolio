Automation Exercise - https://automationexercise.com

เว็บไซต์นี้สร้างขึ้นเพื่อให้นักทดสอบซอฟต์แวร์ (QA Tester) ทุกระดับใช้ฝึกฝนการทดสอบทั้ง UI Testing และ API Testing
จำลองเป็นร้านค้าออนไลน์ขายเสื้อผ้า แบ่งเป็นหมวด Women, Men และ Kids มีสินค้าหลายสิบรายการจากหลายแบรนด์
รองรับการสมัครสมาชิก, Login, ค้นหาสินค้า, เพิ่มสินค้าลงตะกร้า และ Checkout พร้อมชำระเงิน
จุดเด่นคือมี Test Cases สำเร็จรูป 26 ข้อให้ฝึกทำได้เลย และมี API List สำหรับฝึก API Testing โดยเฉพาะ
ไม่มีการซื้อขายจริง ใช้เพื่อการเรียนรู้และฝึกทดสอบเท่านั้น
